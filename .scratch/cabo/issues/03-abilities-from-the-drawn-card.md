# 03: Abilities fire straight from the drawn card

**What to build:** A fresh 7-12 from the draw pile can be used as its ability (peek own / spy other / swap any two) instead of a plain discard. The separate ability phase and the skip action are gone.

**Blocked by:** 01 (Card knowledge travels with the card)

**Status:** done

- [x] Using an ability discards the drawn card and ends the turn
- [x] Abilities are illegal for a card taken from the discard pile and for 1-6/13
- [x] Plain discard of a 7-12 means no ability
